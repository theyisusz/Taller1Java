Instrucciones:
1.En neatbeans se debe clonar el repositorio para visualizar cada uno de los componentes del codigo.
Al ser un repositorio publico no es necesario el uso de credenciales para poder clonarlo, en caso de que si simplemente ingresar el nombre de usuario de github y
su contraseña.
2.Una vez clonado el repositorio se podra ver cada uno de los modulos del proyecto, en este caso 3: p-common, p-core y p-plug-in, si no se vizualizan debe cambiar 
la rama a master es donde estan ubicados estos.
3. Para evitar errores a cada uno de los modulos, dar click derecho , build and clean primero a p-common y p-plug-in y al final p-core que es donde se almacena la calse Main.
4. En p-core se encuentra la clase MainVenta donde podra correr el programa.
